# VOID MVP móvel\n\nMVP instalável como PWA para uso imediato. Roda localmente no navegador, mantém tarefas e histórico em `localStorage`, cria propostas estruturadas e faz somente uma **simulação local** após aprovação explícita.\n\n## Fronteiras\n\n- Não inclui modelo de linguagem nem chama API.\n- Não conecta contas, não lê arquivos, não envia mensagens e não produz efeito externo.\n- A proposta é determinística para manter o comportamento verificável nesta fase.\n\n## Uso\n\nPublique `app/` por HTTPS. No Android, abra a página no Chrome e escolha **Instalar app** ou **Adicionar à tela inicial**.\n
